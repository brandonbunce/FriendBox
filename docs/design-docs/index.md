# Design Docs Index

Design documents record *why* decisions were made, not just what was built. Check here before changing fundamental behavior.

## Adding a design doc

Create a new `.md` file in this directory. Add a row to the table above. Include:
- **Decision**: what was chosen
- **Alternatives considered**: what was rejected and why
- **Consequences**: what this makes easier or harder going forward
